ORION LIVESTOCK - BẢN WEB/PWA - 10 NHÀ NUÔI
Ngày đóng gói: 22/10/2026

MỤC ĐÍCH
- Chạy trực tiếp trên website bằng GitHub Pages.
- Dùng được trên điện thoại Android/iPhone và máy tính.
- Có thể cài như ứng dụng (PWA) từ trình duyệt hỗ trợ.
- Có hỗ trợ mở lại giao diện khi mất mạng sau khi đã truy cập/cài ít nhất một lần.

ĐƯA LÊN GITHUB PAGES
1. Giải nén file ZIP này.
2. Upload TOÀN BỘ các file bên trong vào thư mục gốc (root) của repository GitHub Pages.
3. Settings > Pages > Deploy from a branch > main > /(root) > Save.
4. Chờ GitHub Pages deploy xong rồi mở địa chỉ website.

QUAN TRỌNG
- Không upload nguyên file ZIP làm website; phải giải nén và upload các file bên trong.
- index.html, manifest.webmanifest, service-worker.js, icon.svg, icon-192.png, icon-512.png và orion-logo.png phải nằm cùng cấp ở root.
- Khi thay bản mới trên GitHub, service worker sẽ ưu tiên lấy bản mới khi có mạng.

CÀI TRÊN ANDROID / CHROME
- Mở website bằng Chrome.
- Menu 3 chấm > Cài đặt ứng dụng / Thêm vào màn hình chính.
- Sau khi cài, ORION LIVESTOCK mở như một ứng dụng riêng.

CÀI TRÊN MÁY TÍNH
- Mở website bằng Chrome hoặc Microsoft Edge.
- Chọn biểu tượng Cài đặt ứng dụng trên thanh địa chỉ (nếu trình duyệt hiển thị), hoặc Menu > Cài đặt ORION LIVESTOCK.
- Có thể ghim ứng dụng vào Desktop/Taskbar/Start Menu tùy hệ điều hành.

IPHONE / IPAD
- Mở website bằng Safari > Chia sẻ > Thêm vào Màn hình chính.

DỮ LIỆU
- Dữ liệu của ứng dụng được lưu trên từng trình duyệt/thiết bị. Cài cùng website trên máy khác không tự đồng bộ dữ liệu.
- Nên sử dụng chức năng sao lưu dữ liệu của ứng dụng định kỳ nếu có dữ liệu quan trọng.
